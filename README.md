# Retail Sales Analysis SQL Project

## Project Overview
**Project Title**: Retail Sales Analysis  
**Level**: Beginner  
**Database**: `retail_project`

This project focuses on analyzing retail sales data using SQL in MySQL Workbench. The dataset contains transactional information such as customer details, product categories, quantity sold, pricing, and total sales. The goal of this project is to extract meaningful business insights from the data using SQL queries.

Features
- Database creation and table management using SQL
- Sales analysis by category and customer demographics
- Revenue and transaction analysis
- Customer behavior analysis
- Monthly sales trend analysis
- Top customer identification
- Data filtering and aggregation using SQL functions

## Technologies Used
- SQL
- MySQL Workbench

## Database Schema

The project uses a table named retail_sales with the following fields:

- transactions_id
- sale_date
- sale_time
- customer_id
- gender
- age
- category
- quantity
- price_per_unit
- cogs
- total_sale

## SQL Concepts Used
- SELECT statements
- Aggregate functions (SUM, AVG, COUNT)
- GROUP BY and ORDER BY
- Filtering with WHERE clause
- DISTINCT keyword
- Window functions (RANK)
- Date functions

## Key Insights
- Identified top-performing product categories
- Analyzed customer purchasing patterns
- Determined highest spending customers
- Evaluated monthly sales performance
- Compared sales based on gender and category

## Conclusion
This project helped in understanding how SQL can be used for real-world retail data analysis and business intelligence. It also improved skills in database management, query writing, and data analysis.
